# Multimodal Image Generation Studio

A Generative AI application that converts natural-language prompts into images using Google's Gemini image-generation model.

## Features

- Text-to-image generation
- Custom image prompts
- Prompt payload generation
- Multiple aspect ratios
- Image validation
- Local image storage
- Image download support
